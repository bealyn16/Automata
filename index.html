User Manual

How to use the REGEX Simulator — Group 3 · BSCS34

⬡ Step 1 — Select a Regular Expression

Use the sidebar on the left to choose between RE #1 (alphabet {a, b}) or RE #2 (alphabet {0, 1}). The active RE is highlighted.

⊢ Step 2 — Choose a Formal Language

Click DFA, CFG, or PDA in the sidebar. DFA shows the state diagram. CFG opens a grammar popup. PDA shows the transition table.

↩ Step 3 — Enter a String

Type a string in the Input String field. Use only the symbols from the selected RE's alphabet (a/b for RE#1, 0/1 for RE#2).

▶ Step 4 — Simulate

Click Simulate (or press Enter). The badge turns green (Valid) or red (Invalid). The trace below the diagram shows each state transition.

Reading the DFA Diagram

  • The − symbol marks the start state
  • The + symbol marks accept states (double circle)
  • The orange circle shows the current state during simulation
  • The T state is a trap / dead state — strings reaching it are rejected
  • Arrows between states are labelled with the input symbol that causes that transition
